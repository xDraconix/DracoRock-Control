# DracoRock Control v3.5.1

- Der Panel-Auftrag überwacht automatische systemd-Startwiederholungen bis zum Ergebnis. Ein fehlgeschlagener erster Versuch wird nicht mehr vorzeitig als endgültiger Fehler gemeldet.
- Neustarts gelten erst mit einer neuen Dienstinstanz als erfolgreich. Manuelle Start- und Neustartaufträge erhalten ein neues, weiterhin begrenztes Wiederholungsbudget.
- Vor dem Start wartet der Server bis zu 75 Sekunden auf die tatsächliche Freigabe des konfigurierten NetherNet-TCP-Ports. Dadurch blockieren alte TIME_WAIT-Verbindungen den neuen Listener nicht mehr.
- Die Wartezeit nach dem Konsolenbefehl STOP sinkt von 120 auf 60 Sekunden. Das systemd-Zeitlimit beträgt 65 Sekunden. Bei Überschreitung werden Thread-Wartezustände und I/O-/Speicherdruck protokolliert.
- Konsolenausgaben bleiben in `/var/log/mcbedrock/console.log` erhalten und werden rotiert.
- Installationsvorlagen, Regressionstests und Dokumentation sind aktualisiert.

Für die vollständige Übernahme der Minecraft-Skripte und systemd-Einstellungen ist der vollständige Installer erforderlich. Das eingeschränkte Online-Komponentenupdate verändert diese geschützten Dateien weiterhin nicht. Der Installer führt keinen automatischen Minecraft-Neustart aus.

Die beobachtete Verzögerung beim Herunterfahren durch I/O-Wartezeiten im Host-/Container-System wird damit nicht behoben. Nach Ablauf der STOP-Frist kann systemd den Server terminieren.

Für das signierte Release werden das Installations-ZIP, dessen Manifest und die Manifest-Signatur benötigt. Ein Git-Tag oder das automatisch von GitHub erzeugte Quellcodearchiv allein ersetzt diese Dateien nicht.
